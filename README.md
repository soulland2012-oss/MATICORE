# Мантикора — портал ролевого проекта

Статический сайт без сборки: HTML, CSS и обычный JavaScript.

## Запуск

Откройте `index.html` в браузере — сайт работает прямо из файла.

Для локального сервера (удобнее при правках):

```bash
python -m http.server 8000
```

После запуска сайт доступен по адресу http://localhost:8000.

## Где что лежит

```
index.html                 каркас страницы и порядок разделов
assets/css/main.css        стили: токены, компоненты, разделы, адаптив
assets/js/data/            ВСЕ тексты, цены и правила — правьте здесь
  site.js                  навигация, первый экран, бегущая строка, контакты, фон первого экрана
  lore.js                  сюжетные блоки и временная линия
  fortum.js                река, берега, районы
  factions.js              фракции и Пепельник
  economy.js               цены и допущения калькулятора бюджета
  rules.js                 вкладки правил, формулы, примеры, калькуляторы
  implants.js              каталог имплантов, типы, категории
  anketa.js                шаблоны анкет (дословно), заметки администрации, концепции
assets/js/core.js          утилиты, маршруты #раздел?параметры, звук, глитч
assets/js/art.js           встроенная SVG-графика (районы, лор, эмблемы, схема тела)
assets/js/hero.js          панорама Фортума на canvas и параллакс
assets/js/sections/*.js    логика разделов
assets/img/                место для своих иллюстраций (см. assets/img/README.md)
```

## Как править данные

- В текстах из `data/*.js` работает мини-разметка: `**жирный**` и `[ссылка](#якорь)`.
- Якоря с параметрами:
  - `#fortum?d=kreiner` — открыть район на карте;
  - `#factions?f=asury` — перейти к фракции;
  - `#rules?tab=crit` — открыть вкладку правил, `&s=crit-special` — конкретный раздел;
  - `#implants?cat=skin&type=military&narr=yes&stat=str` — каталог с фильтрами, `#implants?id=kanwar` — конкретный имплант;
  - `#anketa?type=mage` — конструктор анкеты мага;
  - `#world?b=abyss` — открыть полный текст сюжетного блока.
- Новый имплант — новая строка в `implants.js → list`. Он сам появится в каталоге, фильтрах, счётчиках и в разделе правил «Импланты, влияющие на показатели», если у него заполнено поле `stats`.
- Контакты и ссылку на чат впишите в `site.js → contacts`. Пока список пуст, блок контактов не выводится.

## Что сделано по материалам

- Все тексты, цены, числа и механики взяты из лорбука проекта.
- Если поле в материалах не раскрыто (например, отношения «Урканата» с властью), на сайте написано «В материалах не указано».
- Карта Фортума схематичная: соблюдены берега и соседства из лорбука, положение Пепельника условное. Это подписано под картой.
- Пометка «Норративный» из материалов выводится как «Нарративный». Название меняется в `implants.js → narrative.label`.
- В материалах 85 имплантов: у рук пять военных, у остальных категорий по 12.
- Эмблемы фракций и иллюстрации декоративные. Они не добавляют фактов в канон.

## Доступность и движение

- Управление с клавиатуры: ссылка «Перейти к содержанию», заметный фокус, вкладки правил переключаются стрелками, районы карты выбираются через Tab + Enter, Esc закрывает меню и диалоги.
- При системной настройке «уменьшить движение» отключаются параллакс, анимация панорамы, глитч и бегущая строка.
- Звук (фоновый гул) включается только кнопкой «Звук» в шапке.
